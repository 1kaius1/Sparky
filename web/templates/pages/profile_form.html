This name is the model id clients use: it is what API clients and editor extensions list and must send as model, and it must be unique. Use letters, digits and . _ - : only, at most 64 characters, starting with a letter or digit - no spaces or commas. A / is allowed between parts (team/qwen3:7b), but some clients treat / and : specially, so prefer plain names.
Make it self-describing, because several profiles can load the same model with different engines or parameters and every one needs a name that tells it apart. A good shape is <model>-<quantization>-<engine>-<what differs>, for example Qwen3-Coder-Next-NVFP4-GB10-vllm-tp2-ctx32k. Avoid names starting with o and a digit, or containing gpt-5, claude, codex, grok-4 or deepseek-r: some clients change how they send requests when an id looks like those.
