Container cleanup

When an instance ends, its container can be left behind on the node. This page asks every node what it holds and lists the ones that are stale: the instance is over and the container has been stopped for at least {{.Data.MinAgeHours}} hours (the minimum age, set under Settings). Removing one saves its log first, to Container logs; if the log cannot be saved the container is kept. Nothing running, and nothing whose instance is still running, is ever removed.
