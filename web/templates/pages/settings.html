Stale container monitoring

{{if .Data.StaleError}}
{{.Data.StaleError}}
{{end}} {{if .Data.StaleSuccess}}
Stale container monitoring updated.
{{end}}

When an instance ends, its container can be left behind on the node. This finds them on a schedule. None does nothing. Report raises an alert to the Admins listing them. Prune removes them, saving each container's log first. A container that is running, whose instance is still running, or that stopped less than the minimum age ago is never touched, and one whose log cannot be saved is kept. The Container cleanup page lists them at any time and removes them one at a time.
